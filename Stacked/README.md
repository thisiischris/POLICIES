# Stacked — Your Cards, Finally Organized

**Stacked** is the credit card wallet you've always wanted. Add all your cards in one place and instantly see what each one earns, what you owe, when payments are due, and how much your rewards and perks are actually worth. No account required. No internet needed. Your data never leaves your phone.

---

## What Makes Stacked Different

Most people carry 3–6 credit cards and can barely remember which one earns the most at restaurants, when the annual fee hits, or how far along they are on a sign-up bonus. Stacked keeps all of that in one clean, beautiful place — so you're always using the right card and never leaving rewards on the table.

---

## Features

### Your Whole Wallet at a Glance
- Swipeable card stack or scrollable list — your choice
- Search and filter by network, category, personal vs. business, or favorites
- Smooth, gesture-driven navigation that feels like a real wallet

### Everything You'd Ever Want to Track
- **Rewards** — see exactly what each card earns across dining, groceries, gas, travel, and more
- **Rotating categories** — never forget to activate or max out your quarterly 5% cash back
- **Sign-up bonus tracker** — know exactly how much you need to spend and by when
- **APR & promos** — track your regular APR alongside any 0% intro windows
- **Credit limits & balances** — monitor your utilization at a glance
- **Due dates & statement closing** — a built-in calendar so you never miss a payment
- **Annual fees** — see what each card costs you across the year
- **Perks & credits** — Uber Cash, travel credits, statement credits — track what you've used
- **Milestone rewards** — annual free night certificates, spend thresholds, holding benefits

### Portfolio Overview
- Total available credit, combined balance, and utilization across all your cards
- Side-by-side APR breakdown so you know where to pay first
- Expiring promos and grace period alerts

### Privacy Built In
- One-tap balance masking hides all numbers when you need discretion
- 100% local — no accounts, no servers, no tracking of any kind

### Looks Great Too
- Light, dark, and system-adaptive themes
- Beautiful card art for 60+ popular cards built right in

### Bulk Import
- Already have your cards in a spreadsheet? Import them all at once from Excel or CSV

## Getting Started (Developers)

### Prerequisites
- Node.js 18+
- Expo CLI
- Expo Go on your device, or an iOS/Android simulator

### Install & Run

```bash
git clone <repo-url>
cd StackedApp
npm install
npm start
```

Scan the QR code with Expo Go, or press `i` for iOS simulator / `a` for Android.

### Scripts

| Command | What it does |
|---|---|
| `npm start` | Start the dev server |
| `npm run ios` | Open on iOS simulator |
| `npm run android` | Open on Android emulator |
| `npm run web` | Open in browser |

## Tech Stack

Built with Expo SDK 55, React Native 0.83.6, and TypeScript. Animations via React Native Reanimated 4 and Gesture Handler. All data stored locally with AsyncStorage — nothing hits a network.
